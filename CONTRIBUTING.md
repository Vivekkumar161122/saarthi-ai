# Contributing to Saarthi AI (सारथी)

Thank you for your interest in contributing to **Saarthi AI**, an open-source copilot and advocate for gig and informal workers worldwide.

## Code of Conduct

We are dedicated to providing a welcoming, inclusive, and harassment-free experience for everyone. Please be respectful and empathetic in all interactions.

## How to Contribute

1. **Fork the Repository** and clone your fork locally.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Install Dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```
4. **Run Tests**:
   ```bash
   npm test
   ```
   Ensure all existing tests pass and add unit tests for any new business logic.
5. **Accessibility (A11y) Guidelines**:
   - Ensure all interactive elements maintain a minimum touch target size of 48x48px.
   - Verify keyboard navigability and high-contrast color visibility.
   - Keep language outputs at a 5th-grade reading level.
6. **Submit a Pull Request**:
   - Open a PR against `main` with a clear description of the problem solved.

## Security Disclosures

If you discover a security vulnerability or PII leakage bug, please open a private security advisory on GitHub or email the maintainers directly.
